# Appendix: The Zen of System 3

```text
>>> import system3

The Zen of System 3

Complexity over engineering.
Emergence over design.
Capacity over power.

Conditions over commands.
The farmer grows nothing. The plant does.
Let the work change the architecture.
A better answer is easier to recognize than to specify.
Too little structure gives chaos an API key.

Ask who is inventing the next move.
The judge must be harder to change than the thing it judges.
Discovery before polish.
Keep a strange branch alive long enough to test it.
If you can go for coffee, the evaluator stayed behind.

Where nothing can be scored, judgment has to be built.
Build it between evaluators. Inside one, it is an opinion.
Tell the builder the problem, not the test.
Nothing crashes when the mistake is coherent.
A simulated student finds problems. Only a student learns.

System 1 proposes.
System 2 deliberates.
System 3 checks.

Ground every claim. Trace every source.
Trust is local. So is memory.
Testimony comes with metadata.
A record outlives the clerk.
Remembering is not knowing.
A bad rule written down is a hallucination with better retention.

A rule without a mechanism is a wish.
Five judges sharing one source are one witness.
A second witness must be able to be wrong differently.
Reality retains the right to be rude.
A failed test blames the whole bundle. Find the part.
Whoever gets the next agent decides what can be found.
Keep some of the budget away from the leader.
An objection must be able to change what happens next.

None of this is new. We call it science.

Let knowledge accumulate. Let it be overthrown.
A feather is not a reason.
Patterns over recipes.
Say what the result would mean before it arrives.
Give every claim an address, so a correction has somewhere to go.
"Noted" is not an answer.
Session turnover is not a funeral.
Investigate the procedure too.

Self-reference is not self-improvement.
A learner looks autonomous once the teacher is in the walls.
Better under which conditions? Better for whom?
The student will find the gradebook.
The judged do not amend the judge alone.
Doing as well with less is an improvement.
Do not stack revisions on evidence that has not arrived.

The overseer is not ground truth.
Reasons travel further than rules.
Doubt needs someone to call.
Science or authority? Watch what happens to an objection.

Let go of the path, not the boundary.
The human stays in the loop that changes the loops.
A prompt is evidence, not the objective.
You cannot want what you cannot imagine.
A human is not a context window.
Changing what people want is the cheap way to please them. Don't.
Scaffold. Don't substitute.
Leave the human room to change their mind.
Leave people better at wanting than you found them.
Spend attention where it changes the result.

Form the institution the request needs. Take it down afterwards.
Invisible by default. Legible on demand.
The weights will eat the scaffolding. Keep the check outside.
Fold the scaffolding away. Keep the reasons.
Trust what you have learned. Reopen it on purpose.

The default is one strong agent.
An org chart is a feather until it beats one.
A philosophy of emergence should be willing to lose an A/B test.
Hold part of the referee where the makers cannot see it.

Seeing what is wrong is cheap. Building another is not.
Past the peak every story fits. Write down the rule that chooses.
Knowing what works does not settle who gets to decide.
Write the objective where the people it affects can argue with it.
Borrowed capacity belongs to whoever holds the switch.
Some capacity should stay expensive on purpose.
What became easy may still be worth doing.
Capacity creates possibilities. We still have to choose.
Nobody needs a comparative advantage to justify dinner.
Construct knowingly. Build anyway.

The tongue cannot reach the ear.
Build a system that can check.
```
