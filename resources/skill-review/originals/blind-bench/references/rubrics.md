# Rubrics

## v2 — reader experience (default)

Each criterion judged head-to-head: X, Y or tie. Overall pools all criteria with equal weight (win 1, loss 0, tie ½); per-criterion scores are separate fits.

| Criterion | Asks | Anchor |
|---|---|---|
| big_ideas | The larger, more portable central idea, statable in one sentence and still significant | Win: "Wheat domesticated us" (Sapiens 5); "five judges sharing one source are one witness" (System 3 Ch 5). Lose: a well-organised survey with no claim of its own (Life 3.0 Ch 3) |
| thought_provoking | Leaves you arguing with it afterwards; disturbance, not size | Win: ending on a question you can't dismiss ("what do we want to want?", Sapiens 20) |
| engagement | Holds attention through the difficult middle, not just the opening | Win: technical content carried by a person or a stake (Robbie and Harriet, Human Compatible 8) |
| fun | Actual pleasure: laughs, delight, play | Not momentum, not insight |
| momentum | Structural pull: setups, open questions, handoffs | |
| prose | Sentence quality: rhythm, precision, compression, voice | |
| awkwardness | Fewer trust- or immersion-breaking moments (flat jokes, register lurches, self-promotion, visible scaffolding, name-dropping, production artifacts) | The less awkward chapter wins |
| novelty | Newer ideas and framings relative to the chapter's own publication date | Judged against the book's date, so older classics aren't penalised for being old |

Under v2, System 3 moved into a near-tie with Sapiens for first place (chat-only run, author known to the judge; unconfirmed).

## v1 — academic (superseded)

Insight, rigor/evidence, prose/clarity, engagement. Weaknesses: no level anchors; engagement and prose overlap; one bar for all chapter types; rigor a quarter of every match, so Sapiens topped the table with the worst rigor profile and Human Compatible finished mid-table with the best.
