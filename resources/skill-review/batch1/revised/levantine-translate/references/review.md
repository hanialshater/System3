# Review

## Rubric for a translation (score each /10, then overall)

| Dimension | What it asks |
|---|---|
| Fidelity | Nothing omitted, nothing invented beyond flagged flourishes |
| Voice | Sounds like Hani's Arabic (`author-arabic-sample.md`, or voice.md if it is empty: say which), jokes survive unexplained, aphorisms stay aphorisms |
| Idiom | Reads as written in Arabic, not decoded from English |
| Terminology | One rendering per concept; code terms Latin; glossary respected |
| Register consistency | One register held; deliberate winks only; Jordanian rather than Syrian/Lebanese forms in a blog target |
| Seeds | Every easter-egg-register seed carried bare, same Arabic word each time, not explained in text or note |
| Apparatus | Footnotes, names, quotations, links handled as the English now handles them |

For a whole-book comparison of two translations add: completeness, colloquial depth, editorial improvement, chapter-title craft, production readiness. Then recommend how to combine them.

Evaluate a translation as a translation. Don't re-score the argument unless asked.

## Proofing list for Hani's own Arabic drafts

- Dialect slips and verb forms (بنكتشف، حدا; «منقدر» vs «بنقدر»: ask which is his).
- Garbled sentences («بس ما اللي وصفه هيوم مسألة فلسفية بتنتظر حل»).
- An old and a revised paragraph left side by side.
- Overclaims stated as mechanism (Hume → ML presented as *the* mechanism, contradicted two pages later by «رهان قريب من رهان هيوم»).
- Bullet lists where prose belongs; they read as the most generated part.
- A long prologue of essays that promise a narrative before the narrative starts.
- Overlap with the English book: the same opening, joke or lineage in both. Decide which book owns it (Hani has accepted the Leibniz/uncle-joke overlap between System 3 and the blog).
- Open loops in a blog part that readers may not return to for months: turn IOUs into a short map of the next part.
- Sentence-level fixes over rewrites once the arc works; then move on to the next part.

## Verifying a live blog page

The fetcher can serve a stale copy. If the page looks unchanged after a revision, ask for one phrase that exists only in the new version, or for the markdown, before concluding nothing changed.
