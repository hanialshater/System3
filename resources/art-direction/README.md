# Current artwork direction

The selected illustrated edition is implemented in `book-design/curated/`.
Use [the opener register](chapter-openers.md) to find current artwork, and
[the PDF workflow](../../book-design/PDF.md) to build it.

## Working rules

- Preserve selected compositions, faces, lettering and the distinction between
  original masters and enhanced print derivatives.
- Use the selected artwork's watercolor-and-ink treatment as the visual reference.
  Do not regenerate an opener merely because an old brief asks for it.
- Attach interior art to a unique passage in `curated/art.json`, not a historic
  page number. Inspect placement again after text or layout changes.
- Keep originals and provenance. Enhanced pixels do not establish captured detail.
- Require 300 PPI at placed size. Printer-specific bleed, binding geometry, output
  profile and a physical proof remain pending printer selection.

The [Chapter 5 composition experiment](../../book-design/paged/README.md) has
its own contours and cutouts. Its full-image opener is preserved. Adoption of
that experiment across the book is a separate decision.
