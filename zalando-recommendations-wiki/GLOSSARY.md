# Glossary

Shared vocabulary for this wiki. Use these terms consistently across files so notes stay comparable.

- **Signal** — a directly observable fact about a customer session (pages viewed, filters applied, size chart opened, item saved, item returned, time on page, etc.), as opposed to an inference made from it.
- **Need** — an inferred, bounded problem the customer currently has (e.g. size anxiety, comparison friction). Inferred from signals, not observed directly. See [needs/](needs/README.md).
- **Persona** — a named, recurring cluster of behavior (e.g. deal hunter, brand loyalist). A lens for noticing patterns and building intuition, not a label to permanently attach to a real customer. See [personas/](personas/README.md).
- **Style tag** — a label describing a customer's aesthetic or silhouette preference, held as a small weighted set rather than a single archetype. See [styles/](styles/README.md).
- **Pattern** — a "for situation X, do Y" rule connecting a detected need/signal to a concrete action. See [patterns/](patterns/README.md).
- **Commentary** — the explanatory text shown alongside a recommendation (why this item, how it fits, what we know and don't). Distinct from the recommended item itself. See [commentary/](commentary/README.md).
- **Evidence tier** — how much real data backs a specific claim (e.g. a fit claim). Determines what commentary is allowed to say. See [commentary/hedging-fit-claims.md](commentary/hedging-fit-claims.md).
- **Cold start** — a customer session with too little signal to support personalized-sounding claims. See [patterns/for-cold-start-do-honest-popularity-framing.md](patterns/for-cold-start-do-honest-popularity-framing.md).
- **The loop** — the try/search/eval/improve/note cycle this wiki is built around. See [process/try-search-eval-improve-loop.md](process/try-search-eval-improve-loop.md).
