# Styles

How to read and tag a customer's style. Two different layers exist and answer different questions — don't collapse them into one.

- **[classic-style-archetypes.md](classic-style-archetypes.md)** — slow-moving silhouette preference (what shape/line flatters or suits them). Stable across years.
- **[modern-aesthetic-tags.md](modern-aesthetic-tags.md)** — fast-moving aesthetic/vocabulary preference (what look they're currently searching for). Rotates on a trend cycle, sometimes within months.
- **[style-profiling-methods.md](style-profiling-methods.md)** — how real styling services (Stitch Fix, Trunk Club, Zalando's own quiz) actually capture this, worth copying.

## The core rule

Model style as a **small weighted set of tags**, not a single forced archetype — one durable silhouette tag plus zero or more current aesthetic tags, the same way [../needs/README.md](../needs/README.md) models needs as a weighted set rather than a single funnel-stage label. Don't infer any style tag from fewer than a few viewed-or-saved items or an explicit quiz answer — see [../process/signal-checklist.md](../process/signal-checklist.md).
