# Modern aesthetic tags (microtrends)

**evidence: sourced**

The fast-rotating half of a style fingerprint — the vocabulary customers themselves search with. A widely used "12 style aesthetics" consumer-facing framework and its neighbors:

- **Minimalist / Clean Girl** — polished basics, neutral tones, simple fitted silhouettes.
- **Streetwear** — oversized graphics, cargo, chunky sneakers, comfort-as-self-expression.
- **Preppy** — Ivy-League crispness: blazers, loafers, pleated skirts, sweater vests.
- **Boho** — flowy fabric, layered jewelry, earthy tones, fringe/crochet.
- **Athleisure** — leggings/hoodies elevated with structured pieces for everyday wear.
- **Old Money / Quiet Luxury** — heritage tailoring, muted neutrals, no visible logos; restraint signals status.
- **Coastal Grandmother** — breezy linen, sundresses, straw accessories, pastel/cream/blue palette; softer and more lifestyle-driven than preppy.
- **Cottagecore / Dark Academia / Y2K / Coquette** — internet-native, TikTok/Instagram-driven, fast-rotating identity signals rather than durable wardrobes.
- **Grunge/Edgy** and **Business/Smart Casual** — occasion-adjacent tags rather than pure aesthetic ones.

Sources: https://whatcolorssuitme.com/aesthetics/ · https://blog.depositphotos.com/modern-nostalgia-microtrends-aesthetics-2024.html

## Why this layer is useful

This is the layer to use for [../needs/discovery-vs-targeted-search.md](../needs/discovery-vs-targeted-search.md)'s exploratory mission — customers search by these names directly ("quiet luxury," "coastal grandmother"), so recognizing and matching this vocabulary in commentary and curated collections captures demand keyword search alone would miss.

## Caution

These tags rotate fast — a tag that fit a customer's browsing six months ago may not now. Re-derive this layer more aggressively than [classic-style-archetypes.md](classic-style-archetypes.md); don't treat it as a durable characteristic.
