# Patterns: for X, do Y

Fast lookup from a detected situation to a concrete action. Each pattern names its trigger signals, the action, why, the anti-pattern, and its evidence status. Start here once you've got a candidate need from [../needs/README.md](../needs/README.md) or a signal read from [../process/signal-checklist.md](../process/signal-checklist.md).

| Pattern | Trigger | Status |
|---|---|---|
| [for-comparison-friction-do-comparison-rx.md](for-comparison-friction-do-comparison-rx.md) | repeated switching between a small set of specific items | evidence: hypothesis |
| [for-size-anxiety-do-evidence-gated-fit-note.md](for-size-anxiety-do-evidence-gated-fit-note.md) | size chart opened repeatedly, no add-to-bag | evidence: sourced |
| [for-cold-start-do-honest-popularity-framing.md](for-cold-start-do-honest-popularity-framing.md) | below minimum viable signal set | evidence: sourced |
| [for-decision-paralysis-do-curate-not-expand.md](for-decision-paralysis-do-curate-not-expand.md) | large, near-identical assortment on a category page | evidence: sourced |
| [for-unfamiliar-brand-do-surface-social-proof.md](for-unfamiliar-brand-do-surface-social-proof.md) | first-time exposure to a brand, no purchase history with it | evidence: sourced |
| [for-occasion-need-do-check-collection-match.md](for-occasion-need-do-check-collection-match.md) | occasion-specific browsing (wedding, interview, vacation) | evidence: hypothesis |
| [for-loyal-customer-do-reference-history.md](for-loyal-customer-do-reference-history.md) | repeat purchase history with a brand or category | evidence: sourced |
| [for-plus-size-shopper-do-aggregate-fit-subscore.md](for-plus-size-shopper-do-aggregate-fit-subscore.md) | extended-size filter applied, or plus-size persona signal | evidence: sourced |

Each pattern links back to the need(s) and persona(s) it's most associated with, and forward to the commentary rules that govern how to actually phrase the response. If you apply a pattern and it doesn't hold up, retire it per [../process/try-search-eval-improve-loop.md](../process/try-search-eval-improve-loop.md) rather than silently ignoring it next time.
