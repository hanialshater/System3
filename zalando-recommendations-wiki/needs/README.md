# Needs

Bounded, inferred problems — the actual thing an agent should be trying to address. Not personality traits, not permanent labels: each need is local to a customer, a moment, and a set of signals. See [../process/signal-checklist.md](../process/signal-checklist.md) for what evidence justifies inferring one.

- **[size-fit-anxiety.md](size-fit-anxiety.md)** — the single largest need in the category by volume of evidence.
- **[comparison-friction.md](comparison-friction.md)** — too much choice, not resolved.
- **[trust-and-quality-uncertainty.md](trust-and-quality-uncertainty.md)** — can't judge quality or trust the brand without touching the item.
- **[discovery-vs-targeted-search.md](discovery-vs-targeted-search.md)** — two different missions that need different interfaces.
- **[filter-fatigue-and-choice-overload.md](filter-fatigue-and-choice-overload.md)** — the customer can't narrow down what they're looking at.
- **[jobs-to-be-done-functional-social-emotional.md](jobs-to-be-done-functional-social-emotional.md)** — the frame that catches needs the other files miss: a purchase can serve a functional, social, or emotional job at once.

Each need file links to the pattern(s) in [../patterns/README.md](../patterns/README.md) that respond to it. A need without a matching pattern is a real gap — note it in [../notes/known-gaps.md](../notes/known-gaps.md) rather than improvising silently.
