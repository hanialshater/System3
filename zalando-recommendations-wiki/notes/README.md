# Notes

The living, growing part of this wiki — where the [try-search-eval-improve loop](../process/try-search-eval-improve-loop.md) actually deposits what it learns. Everything else in this wiki is reference; this directory is memory.

- **[what-seems-to-work.md](what-seems-to-work.md)** — confirmed or promising outcomes, dated, with what was tried and why it worked.
- **[what-doesnt-work.md](what-doesnt-work.md)** — dead ends, dated, so nobody re-discovers the same one.
- **[open-questions.md](open-questions.md)** — things this wiki doesn't have a confident answer to yet.
- **[known-gaps.md](known-gaps.md)** — needs, categories, or personas this wiki hasn't built coverage for.

## How to add an entry

Keep it short: what was tried, what happened, and a link back to the wiki file(s) it tested. Date it (use the actual date of the session, not a placeholder). If an entry changes the `evidence:` tag on some other file, update that file too — the note and the tag should never disagree.

These four files start empty (or near-empty) on purpose — this wiki is an experiment that hasn't been run yet. The first entries here are the actual proof this thing works, not the reference pages.
